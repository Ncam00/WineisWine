Core AI Agent System

Instead of one AI chatbot, you create multiple specialized agents.

Each agent has a role.

Wine Valuation Agent
Purpose:

Tracks market prices

Updates wine values automatically

Detects appreciation/depreciation

Estimates portfolio growth

Tasks:

Scrape pricing APIs

Compare recent sales

Estimate market value

Alert users of major price moves

Example:

“Your 2016 Screaming Eagle increased 12% this month.”

This becomes your:

“stock market tracker for wine”

Cellar Intelligence Agent
Purpose: Understands the user’s collection.

Analyzes:

Regions

Grape exposure

Vintage diversification

Drinking windows

Investment balance

Example:

“Your cellar is overexposed to Napa Cabernet.”

or

“You own mostly near-peak wines. Consider younger Bordeaux.”

This makes the app feel premium instantly.

Drink Recommendation Agent
Purpose: Suggest what users should drink next.

Factors:

Peak maturity

Food pairing

Weather

Mood

Occasion

Portfolio strategy

Example:

“Tonight is ideal for your 2019 Central Otago Pinot Noir.”

Very engaging daily-use feature.

Buying Opportunity Agent
Purpose: Find undervalued wines.

Monitors:

Retail sites

Auctions

Market trends

Region popularity

Then:

“This Barolo appears 18% below market average.”

This is where power users stay subscribed.

Fraud / Authenticity Agent
Massive future potential.

Checks:

Suspicious pricing

Fake wine indicators

Provenance issues

Auction irregularities

High-end collectors would LOVE this.

Portfolio Growth Agent
Acts like a financial advisor.

Analyzes:

ROI

Market performance

Best-performing regions

Long-term appreciation

Example:

“Your Burgundy collection outperformed Bordeaux by 14% this year.”

This is where you can justify premium pricing.

Cellar Automation Agent
This is the “self-running” magic.

It:

Auto-updates values

Auto-categorizes wines

Suggests drinking timelines

Detects duplicates

Recommends storage improvements

Cleans bad entries

User barely needs to manage anything manually.

Smart Notification Agent
Instead of annoying notifications:

Only important insights

Personalized alerts

Examples:

“2 wines are entering peak maturity.”

“Your cellar value crossed NZ$10,000.”

“Market demand for Champagne is rising.”

Sommelier Conversation Agent
Natural language AI.

User asks:

“What’s my best steak wine?”

“What bottle should I gift?”

“Which wines are underperforming?”

This makes the app feel alive.
